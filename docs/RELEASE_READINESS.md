# Release Readiness and Manual QA

This project is **in active development**, not a signed-off release candidate. Passing GitHub Actions is necessary but not sufficient for all phases of the master specification.

## Automated acceptance

- `npm run typecheck` — strict TypeScript.
- `npm test` — deterministic physics/combat/progression tests.
- `npm run build` — deployable static Vite bundle.
- `npx playwright install chromium && npm run test:e2e` — browser gameplay, settings, biome renders, live boathouse crossing, game-over and retry.
- CI screenshot artifacts provide representative visuals but still require review.

## Manual playtesting required before claiming complete

- [ ] Complete **three uninterrupted 15-minute sessions** on Classic, Modern and Endless modes.
- [ ] Reach all five environments through natural gameplay and verify car/boat handoffs and collision fairness.
- [ ] Test truck call/docking success and failure, replenishment and safe deployment.
- [ ] Verify missiles against helicopters; oil, flaming wake and smoke against representative threats; civilian scoring lockout.
- [ ] Record 1080p average/1% low FPS on mainstream discrete and integrated GPUs, at each quality preset.
- [ ] Check WebGL context loss/recovery and memory trends after a 30-minute play session.
- [ ] Test Chrome, Edge, Firefox and Safari where WebGL2 support exists; keyboard and at least two gamepad layouts.
- [ ] Inspect screenshots for road seams, contrast, speed readability and effects visibility; approve visual baselines.
- [ ] Check accessible keyboard navigation, key rebinding, reduced motion, high-contrast HUD and mute.
- [ ] Review third-party license notices, original art/audio provenance and product title legal clearance.
- [ ] Generate and commit a version-locked package-lock.json, switch CI to npm ci, retest fresh install.

## Known limitations

Road forks and branch selection, sophisticated boathouse interior transformation, advanced AI orchestration, richer authored audiovisual assets, full gamepad remapping, and reproducible hardware performance results remain work items. Consult [ROADMAP.md](../ROADMAP.md), not checkbox counts alone, for scope and status.

## Deployment

The production bundle is generated by `npm run build` in `dist/`. Deploy this directory to static HTTPS hosting with appropriate fallback and asset caching. Verify WebGL2 detection and music/audio autoplay restrictions on the target host. No production hosting endpoint is configured in this repository.
